# crea-una-landing-espectacular-para-emprendimiento-

Generado para: Crea una landing ESPECTACULAR para emprendimiento de jabones artesanales hechos a mano. Hero con imagen de fondo de jabones artesanales (Unsplash), overlay suave, título llamativo. Menú sticky arriba: Inicio, Nuestros Jabones, Aromas, Cómo Pagar, Contacto. Sección Nuestros Jabones: 3 cards con foto, nombre (ej: Barra Clásica, Jabón Exfoliante, Jabón Líquido) y descripción breve. Sección Aromas: grid de cards con lavanda, rosa, vainilla, eucalipto, cítricos. Sección Métodos de pago: transferencia, tarjeta, efectivo, Mercado Pago. Footer con redes sociales (Instagram, WhatsApp, Facebook), dirección o contacto. Paleta rosa pastel, blanco, morado. Cards con rounded-xl, shadow, hover elegante. Todo en español.
